# HidroPro para Revit

Instalador oficial do **HidroPro**, plugin de dimensionamento e modelagem hidrossanitária para o Autodesk Revit.

### [⬇ Baixar o instalador mais recente](https://github.com/italooliveira9613-pixel/HidroPro-Downloads/releases/latest/download/HidroPro-Setup.exe)

## Antes de instalar

- **Requisitos:** Windows 10 ou 11 e Autodesk Revit 2024, 2025, 2026 ou 2027. A biblioteca de famílias e o Preparar Projeto funcionam a partir do Revit 2025.
- **Feche o Revit** antes de instalar. O instalador não pede permissão de administrador: instala só para o seu usuário do Windows.
- **Aviso do Windows:** ao abrir o instalador, o Windows pode mostrar "O Windows protegeu o computador". Clique em **Mais informações** e depois em **Executar assim mesmo**.

## Depois de instalar

Abra o Revit e procure a aba **HidroPro**. As Ferramentas Rápidas são gratuitas. As demais pedem uma assinatura ativa: entre pelo botão **Conta**, com o mesmo e-mail da compra.

## Conferir o download

Cada versão traz nas notas o SHA-256 do instalador. No PowerShell:

```powershell
Get-FileHash .\HidroPro-Setup.exe -Algorithm SHA256
```
